{# ---------------------------------------------------------- How it works #}

How it works

Three steps, repeated

  1. 1

    Solve a DSA problem

    Pick a problem from the roadmap, write your solution in Python and submit it.

  2. 2

    Review your results

    See which test cases passed, then check how your performance in that topic is changing.

  3. 3

    Practise what is recommended

    Follow the suggested next activity, together with the reason it was chosen.

About the project

A student project built to be explained

DSA Path is an educational project developed by a student as a B.Tech Project-1 at Medicaps University. It records every attempt, calculates topic-wise performance, and recommends the next activity.

Recommendations start with clear, simple rules. When enough attempt data has been collected, a machine-learning model can help choose between problems. Until then, the rules work on their own.
